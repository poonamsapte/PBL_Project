# Ozone Mall, Ojhar — Interactive Website Demo

## Files
- index.html — main app shell
- styles.css — complete responsive premium UI
- app.js — pages, routing, filters, search, modals, forms, admin demo
- data.js — all demo content in one place

## Run
Extract the ZIP and open `index.html`.

For best results use VS Code + Live Server, or:
`python -m http.server 5500`

Then open `http://localhost:5500`.

## Demo pages
Use the top navigation or these hashes:
#home
#shops

#ent
#offers

## Important
The image URLs are high-quality demonstration images. Before showing the final client demo, replace the main hero/gallery images with the actual approved Ozone Mall, Ojhar photographs.

Demo shop names, offers, movies, timings and contact details are intentionally not presented as confirmed official information. Replace them with information supplied by management.
